# Nexus AI

Aplicação web Nexus AI, construída com Next.js 14, React 18 e Node.js.

## Configuração

1. Instale as dependências com `npm install`.
2. Copie `.env.example` para `.env.local`.
3. Preencha as variáveis de ambiente necessárias:
   - `GEMINI_API_KEY`
   - `NEXUS_ACCESS_PASSWORD`
   - `NEXUS_SESSION_SECRET`
4. Inicie em desenvolvimento com `npm run dev`.
